## Deliverable
Clear separation of QA outcome, rights assessment, review snapshot, approval decision, authorization decision, execution and distribution outcome. Define protected-action policy contract, evidence requirements, fail-closed cases and acceptance scenarios.

## Boundary
Central authorization is sole authority for protected actions. Approval is not authorization. Do not enable real publishing, relax hard blockers, decide emergency-pause/in-flight external-action policy without owner decision, or create credentials.

## Stop conditions
Missing/ambiguous policy authority, unresolved protected-action catalogue or any bypass path. No external action or implementation without explicit authorization.
