## Known architecture discrepancy
Master Blueprint 2.0 and the proposed research blueprint describe SQLite-first or SQLite-prototype options. Accepted P0 ADR-002 specifies a PostgreSQL-compatible relational database as authoritative shared-state store. ADR-002 wins. SQLite may remain only for bounded legacy/local use if compatible with accepted contracts; it must not become a second authoritative shared-state store.

## Completion and closure rule
Close a gap only with exact source path, section, authority, evidence, reviewer and date. If an owner decision is required, keep OWNER_DECISION_REQUIRED; never invent a resolution. File presence or a successful move is not proof of design acceptance or implementation.
