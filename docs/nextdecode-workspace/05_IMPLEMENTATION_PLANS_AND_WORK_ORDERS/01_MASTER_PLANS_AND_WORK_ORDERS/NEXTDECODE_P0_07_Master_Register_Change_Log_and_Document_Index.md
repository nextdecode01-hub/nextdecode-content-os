## 5. Authority rules

- Accepted owner decision records and accepted ADR/CF sources govern their exact decisions.
- Specifications and standards govern only within their approved scope.
- Reconciliation files are proposals unless explicitly accepted.
- This index is navigation and coordination, not a replacement for authoritative source documents.
- A generated document does not become authoritative merely because it is newer or included in this package.
- No file in this batch records new owner approval, contract freeze, implementation authorization or test execution.
