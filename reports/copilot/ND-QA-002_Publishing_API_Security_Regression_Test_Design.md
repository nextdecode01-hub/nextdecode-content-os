## Smallest useful first milestone

Start with five parameterized/focused tests: **#1–#5** (all direct publisher adapters reject absent/stale approval, including the `publish_social` CLI bypass) and **#10–#11** (API authentication and payload validation). These close the immediate authorization entrypoints with mocked clients and no live services. Next milestone: #6–#9 to enforce content governance across preflight/render/promotion; then #12–#13 for source policy and distribution reporting.
