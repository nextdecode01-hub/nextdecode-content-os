# ND-QA-003A — Governance Regression Coverage Gap Analysis

**Date:** 2026-11-01  
**Scope:** Newly identified gaps beyond the ND-QA-002 13-case proposal. Read-only; no tests run and no repository changes.

> **Ticket limitation:** ND-ENG-002 was not present in the workspace search. GitHub issue search returned no matching ticket, and `gh` CLI was unauthenticated. This analysis uses the current source snapshot and ND-QA-002 proposal as evidence; verify the recommendations against the actual ticket before test implementation.

## Previous coverage reused (not repeated)

ND-QA-002 already proposed coverage for direct publisher CLI approval, approval mismatch/expiry in general, `publish_social.py` CLI authorization, rights and claim blocking, integrated storyboard gate/direct script generation, API authentication and malformed payloads, Wikipedia exclusion, and aggregate partial-crosspost status. Existing tests already check the approval helper's UTC/IST date behavior and a video-hash mutation (`tests/test_approval_integrity.py`), the standalone storyboard gate (`tests/test_storyboard.py`), low-level rights and evidence review (`tests/test_cutout_rights.py`), and n8n runner bearer auth (`tests/test_n8n_runner.py`). ND-QA-002 tests were proposals, not evidence that these protections are implemented.

## Remaining unknowns

- Exact ND-ENG-002 acceptance criteria and which changes Qoder owns (ticket unavailable as noted above).
- Whether API authentication is in-app or enforced by a trusted reverse proxy; how credentials rotate and whether route-level read access differs from generation access.
- Whether editorial approval may authorize an immediate public release, or a separately versioned authorization/policy decision is required.
- Allowed rights-status set and whether all non-`permitted` states must block every platform/use.
- Which claim statuses are hard blockers versus review warnings; accepted baseline leaves the hard-gate catalogue open.
- Cross-post reconciliation mechanism/platform idempotency guarantees and desired representation for remote-success/local-failure.
