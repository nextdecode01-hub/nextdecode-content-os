# NEXTDECODE reports

Reports, audits, implementation handovers, test designs and verification records are filed here by evidenced provenance.

## Folders

- opencode/ — documents explicitly naming OpenCode as author/owner or preserved from the original opencode/ report folder.
- qoder/ — documents explicitly naming Qoder as the source agent/owner.
- copilot/ — reports from the original copilot report/ folder.
- antigravity/ — report explicitly naming Antigravity.
- deepseek/ — B3 test-design documents whose document IDs identify DeepSeek.
- secondary-agent/ — reports identifying an independent secondary agent without naming the agent.
- unattributed/ — reports whose author cannot be established from the artifact itself.

No report is assigned to Kilo or ChatGPT without explicit provenance evidence. A reviewer named in a report is not automatically its author.

## Preservation rules

- Reports are historical evidence, not current runtime verification unless their exact revision/environment and evidence are revalidated.
- Superseded reports remain preserved; do not delete them merely because a later revision exists.
- Do not promote a report, recommendation, or test result into an owner decision or contract freeze.
- The D-drive canonical P0 workspace remains authoritative for P0 decisions and contracts; this report archive is not a replacement.

See MIGRATION_MANIFEST.md for original paths, attribution basis, hashes, duplicate handling and reference updates.
