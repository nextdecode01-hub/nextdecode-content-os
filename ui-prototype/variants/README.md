## Current hybrid direction

One coherent Content OS experience combining:
- Control Center for overview and decisions.
- Creator Workspace for idea-first entry.
- Workflow Studio for visual execution visibility.
- Insights Console for performance learning.

The hybrid uses the owner's supplied ChatGPT appearance palette as a reference: background `#110A16`, surface `#17111E`, foreground `#92A2B9`, accent `#7A3535`. Dark / Light / System modes are available.

## Comparison rules

- Open each variant's README for preview instructions.
- Keep variants independent until comparative review is complete.
- Shared scorecard: visual quality 25%, workflow usability 25%, responsive behavior 15%, accessibility 15%, component quality 10%, performance 10%.
- Do not select a winner solely on appearance; assess the end-to-end user journey and governance clarity.

All variants use sample data only. They must not connect to backend APIs, change project state, approve work or execute publishing/export actions. Prototype selection does not authorize P1 implementation.
