# NEXTDECODE Hybrid Dashboard v0.2

**Status:** New high-fidelity isolated prototype  
**Entry point:** `index.html`  
**Relationship to v0.1:** Separate version. v0.1 remains unchanged.

## Preview
Open `index.html` directly in a modern browser. The layout is dependency-free. Google Fonts and Unsplash images are remote enhancements; if unavailable, system fonts and image fallbacks are used.

## Design direction
A unified Content OS interface combining:
- Control Center: workspace pulse, active projects, reviews and operations.
- Creator Workspace: dedicated creative entry points.
- Workflow Studio: visually connected stages from discovery through human review.
- Insights Console: performance trends and content learning.

The design uses a dark plum/charcoal palette based on the owner's ChatGPT appearance preference, with richer image-led project surfaces, cinematic hero treatment, denser creative tools and clearer operational hierarchy.

## Included sections
Overview, Projects, Workflows, Research, Studio, Review & Approvals, Publishing, Analytics, Operations and Settings.

## Interactions
- Sidebar navigation.
- Global Dark / Light / System mode with local preference persistence.
- Search for dashboard sections.
- Interactive workflow stage selector.
- Creator tool cards with sample-only preview dialogs.
- Project cards with sample detail dialogs.
- New-project demonstration dialog.
- Review notification feedback.
- Searchable and status-filterable tables in section views.

## Safety and governance
- All metrics, projects, activity and status records are illustrative.
- No backend, API, database, provider, model or account integration.
- No real content generation, project creation, approval, upload, export or publishing.
- Publishing section is readiness-only and disabled for external actions.
- Existing P0 contracts, architecture and governance remain unchanged.
- Prototype does not authorize P1 implementation.

## Known limitations
- This is a static front-end prototype, not a production application.
- Remote image/font availability depends on network access; imagery is decorative sample content.
- Project and creator dialogs are demonstrations, not persisted workflows.
- Authentication, authorization, audit history, real worker telemetry, workflow state transitions and platform analytics are not connected.
- Responsive breakpoints, keyboard focus styling and reduced-motion preference are included; a full assistive-technology audit has not been completed.
- Browser interaction testing should be recorded separately from file-write verification.

## Evaluation
Shared prototype rubric: visual quality 25%, workflow usability 25%, responsive behavior 15%, accessibility 15%, component quality 10%, performance 10%.
