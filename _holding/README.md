# Temporary holding area

Reversible quarantine for dormant or unsafe legacy material. Never import or execute files here in production. Every item requires a manifest entry, SHA-256, reason, caller scan and restore path. Do not delete quarantined material without replacement verification, retention decision and owner approval. This is not runtime storage or a general dumping ground.

The legacy YouTube OAuth helpers manual_auth.py and get_code.py are retained only for reference. They are not an approved re-authentication workflow.
