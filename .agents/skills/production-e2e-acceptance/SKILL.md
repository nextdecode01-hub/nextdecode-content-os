# Production E2E Acceptance

Inspect git status first and preserve all dirty/untracked work. Confirm topic, configuration and provider availability without exposing secrets. Use an isolated run directory; never overwrite a previous successful artifact.

Execute research, claim ledger, script, narration, shot plan, asset resolution, storyboard, render and QA. Check every factual narration sentence against claim IDs and source evidence. Check every visual against its narration beat and reuse rights.

Verify 45-60 seconds, 1080x1920, 30 FPS, audio, caption alignment and stable artifact digest. Confirm the review package belongs to the current run, not a stale queue entry. Stop at human publishing approval. Never publish, upload or schedule public distribution.

Retry only bounded transient/provider failures. Reject irrelevant visuals and unknown-rights assets. Preserve failure artifacts and stage traces. Report exact failed stage, reason, retries and blockers. Never bypass QA, evidence, storyboard, rights, artifact integrity or final approval.
